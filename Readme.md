# 💸 Expense Tracker – HTML, CSS & JavaScript

A simple, responsive **Expense Tracker** built using only **HTML**, **CSS**, and **Vanilla JavaScript**.  
Track your daily income and expenses, manage your budget, and view your spending history—all in one place!

---

## 🚀 Features

- ➕ Add income and expense transactions
- 🗑️ Delete entries with a click
- 💰 Real-time calculation of balance, income, and expenses
- 🧾 Transaction list with descriptions and amount
- 💾 Saves data using `localStorage` (no backend required)
- 📱 Fully responsive and mobile-friendly
